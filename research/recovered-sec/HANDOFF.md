# 已復原的 SEC 實驗

這個僅含原始碼的套件包含於 2026-11-04 從三個研究封存檔復原的確定性 SEC 先導實驗與八季候選稽核。三個封存檔均通過 ZIP CRC 檢查。封存檔校驗值、大小與來源檔案對應見 `../../docs/vendor/recovery-manifest.json`。

匯入內容使用獨立目錄，程式碼不依賴雲端基準。兩個包含 `extract.py` 的封存檔中，該檔案位元組完全相同。匯入保留其原始碼、人工篩選的 `validate.py`、兩套測試、30 家公司名單，以及候選稽核執行器／彙整器。`verify_local.py` 是離線驗證入口。封存執行器的一個行尾空白已正規化；清單同時記錄來源與匯入雜湊。未納入任何外部第三方儲存庫程式碼。

第三個封存檔 `sec-filing-review.zip` 包含審查與腳本，依賴另一個外部儲存庫的固定提交。內容仍在由 Git 忽略的本機匯入目錄；未取得或執行該外部相依程式。歷史輸出、完整申報快照、執行紀錄、環境匯出，以及使用佔位聯絡資訊的先導下載器，均排除於此原始碼套件之外。

## 執行離線驗證

從儲存庫根目錄，使用 Python 3.12 與 `lxml==6.1.1`：

```sh
data/vendor/local/.venv/bin/python research/recovered-sec/verify_local.py \
  --imports data/vendor/local/research-imports \
  --results data/vendor/local/verification
```

此命令需要三個原始封存檔及其解壓目錄。它會驗證封存檔雜湊及三個原始先導申報檔雜湊，執行 3 項先導與 9 項稽核測試，重新解析三份已快取的先導 HTML 快照，執行人工篩選的先導核對，並從已存原始資料項重算已存季度候選資料／分組。它會在本套件下寫出可拋棄的 data/outputs，並在 `--results` 下寫入紀錄。這些路徑均由 Git 忽略。此命令不會發出網路請求。

本機驗證觀察結果：12 項測試通過；人工篩選分組核對 26/26 項通過；30 家公司名單中，全部 234 個已處理季度均重現了已存季度資料項、總額、分組與衝突重複數量。這驗證的是已存實驗的可重現性，不衡量揭露召回率、語意準確性或與 Stock Analysis/Futu 的一致性。

八季 ZIP 包含已存原始候選資料項與輸出，但缺少 `data/` 來源 HTML 快取。因此此檢查不會重新解析 30 家公司的原始 HTML，也不會獨立驗證那些來源快照。先導實驗的三份原始 HTML 位於另一個 ZIP，已在本機重新解析。

## 網路執行器限制

封存的 `eight_quarter_eval/run.py` 保留原始行為，包含預設佔位 User-Agent。它是研究程式碼，並非核准的正式下載器。任何網路執行前，須提供真實且獲授權的 `SEC_USER_AGENT`、審閱 SEC 存取規則，且一次只執行一個下載程序。本工作未執行其網路路徑。網路執行會寫入自己的快取／輸出，皆由 Git 忽略。

原始 README 保留歷史發現與限制。尤其是，總額核對相符不證明組成正確；分類標準階層、實體範圍、重編、修正申報及跨來源語意對應仍需進一步處理。雲端工作採用任何模組前，應將此復原套件與既有基準核對，保留來源追溯資訊，避免將已存候選輸出視為乾淨的營收參考資料。
